# PRD — Birthday

Existing vanilla JavaScript birthday journey with four independently editable slides: Birthday Opening, Her Story, Dream World and Sweet Moments. Preserve personal media and approved artwork. Support desktop/mobile full-viewport panels, accessible buttons, left/right chapter navigation, portrait pose switching, media selection and reduced-motion playback.

Run npm install and npm run dev from Birthday. Development must use localhost:5173 with a strict port. npm run build outputs a production website plus four standalone pages. No runtime framework is required.

This document consolidates the user's requirements; it is not a replacement approved Figma/PRD source. References remain in the supplied sibling references directory.
